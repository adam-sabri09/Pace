## Ownership rules

- Anything under `src/server/` MUST NOT be imported from any client component. Enforced by convention + the `"server-only"` package on entry files.
- Anything under `src/components/ui/` is generated by the shadcn CLI and should not be hand-edited unless necessary.
- Anything under `src/app/` is Next.js routing — one folder per route.
- Migrations are append-only; never edit a merged migration file — write a new one.

## Naming

- Files: kebab-case (`session-card.tsx`).
- React components: PascalCase (`SessionCard`).
- Server actions: verb-noun (`generatePlan`, `skipSession`).
- Types & Zod schemas: PascalCase (`PlanInput`, `SessionSchema`).
